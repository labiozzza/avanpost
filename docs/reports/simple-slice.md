# Минимальный вертикальный срез

Дата: 2026-10-20. Версия: `0.4.0`.

## Цель

Заменить перегруженный отладочный экран простой игровой сценой: один зелёный биом, понятные ресурсы, видимый цикл заготовки и постройки. Разработка side-view beta остановлена до принятия этого среза.

## Что реализовано

- Один Canvas-экран без API, Phaser-сцены и отладочных панелей.
- Сверху: дерево и камень. Снизу: дом, лесопилка, склад.
- Одно дерево, склад, рабочий и две площадки под застройку.
- Клик по дереву → `Рубить`; рабочий идёт, рубит, несёт бревно на склад.
- Дерево даёт 1 бревно и восстанавливается через 3,2 с.
- Дом стоит 3 дерева, лесопилка — 2. Стоимость списывается сразу, затем рабочий идёт строить.
- Видны ходьба, топор, перенос бревна, леса, прогресс работы и готовые здания.
- `?fast=1` ускоряет цикл в 4 раза для проверки и E2E.

## Проверки

| Проверка | Результат |
|---|---|
| `npm run typecheck` | без ошибок |
| `npm run build` | клиент 14,48 KB JS / 5,44 KB CSS, PWA собирается |
| `npm test` | 44 passed |
| `npm run e2e` | 12 passed (desktop + mobile) |
| FPS на viewport 390×844, DPR 2 | 60, p95 кадра 16,7 мс |
| Ошибки консоли | нет |

E2E проверяют стартовый экран, цикл рубки, дом за 3 бревна, отказ при нехватке дерева, запрет второй рубки и PWA-манифест.

## Ограничения

- Состояние живёт только в памяти страницы; перезагрузка начинает сцену заново.
- Камень показан, но пока не добывается и не тратится.
- Лесопилка строится, но не производит ресурсы.
- Серверный I.3, реестры контента и старый Phaser-клиент не подключены к этому экрану.
