# Играть в Avanpost Peace V2

## Проверенные адреса, запущено сейчас

- **Компьютер:** <http://localhost:4175/> (уже подключён; свежий код для телефона сейчас показан в этом браузере)
- **Телефон в той же частной Wi-Fi-сети:** <http://192.168.3.138:4174/>.
- **API health:** <http://192.168.3.138:8788/api/health> → `200`, база `avanpost_v2_dev`.
- **Состояние:** адрес `192.168.3.138` на `en0` повторно проверен; API и оба клиента запущены на этом частном интерфейсе/loopback. V2 PostgreSQL остаётся отдельным на `127.0.0.1:5434`.
- **Pairing-код:** свежий код для телефона уже показан в открытом localhost-браузере на компьютере. Если срок истечёт, нажмите «Показать код на этом компьютере» снова. Handoff работает только локально; код действует пять минут и принимается один раз. В чат его не отправлять.

Физический телефон ещё не проверен. Автоматизированный E2E прошёл с mobile-emulated браузером; G2 остаётся `IN_PROGRESS` до ручного плейтеста.

## Короткий сценарий плейтеста

1. На localhost-компьютере уже подключена игровая сессия; нажмите «Илья · выбрать рабочего», чтобы запустить игру на этом экране.
2. На телефоне откройте <http://192.168.3.138:4174/>. Оба устройства должны быть в одной частной Wi-Fi-сети.
3. Введите в телефон код, показанный на компьютере, и нажмите «Подключить». Код действует пять минут с момента показа и принимается один раз.
4. В выбранном браузере нажмите «Илья · выбрать рабочего», затем «Сходить за деревом». Проверьте, что Илья появился у дерева с бревном; нажмите «Доставить на склад». Повторите доставку, чтобы получить 3 дерева.
5. Нажмите «Построить домик · 3 дерева», затем обновите страницу. Домик и оставшийся запас должны сохраниться.
6. Напишите OpenCode результат на компьютере/телефоне и укажите любые ошибки или неудобства. Не присылайте pairing-код.

Если телефон не открывает страницу, сообщите OpenCode. Не запускайте терминал и не меняйте настройки сети или базы.

- Bundle: `apps/client-v2/dist/assets/index-xS6RVrs1.js`
- SHA-256: `1ca458e623642d18d88e25e6bfbb1ff61da24cb0ce896a16e0722a6a8518e096`
- Source HEAD: `87b463ae225f2c690d80f2cb29bba0f55eb4263a` (изменения рабочей копии включены в указанную сборку).
- Сборка: `npm run build:peace:v2`
- БД V2: `npm run db:peace:v2:up`, затем `npm run db:peace:v2:migrate`
- Диагностика: `AVANPOST_V2_ENABLE_LAN=true AVANPOST_V2_BIND_HOST=192.168.3.138 npm run doctor:peace:v2`
- Запуск API + обоих Vite-клиентов: `AVANPOST_V2_ENABLE_LAN=true AVANPOST_V2_BIND_HOST=192.168.3.138 npm run dev:peace:v2`
- Остановка V2 API и обоих клиентов: `npm run dev:peace:v2:stop`
