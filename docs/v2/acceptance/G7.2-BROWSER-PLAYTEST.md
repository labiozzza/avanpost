## Defects and fixes

- **Resident/training control interaction race (reproduced twice, fixed and regression-passed):** the 250 ms world sync replaced resident buttons and training-option buttons while a user was clicking. `renderWorld` now reconciles resident buttons by ID; `renderTrainingControls` now reuses one button per school and updates it in place. The third run of the same desktop Playwright journey passed.
- **Mobile touch hit-target issues (reproduced and regression-passed):** viewport camera controls now fit the narrow layout; context-panel scroll resets when meaningful content/task identity changes; world taps are constrained to visible ground points inside the canvas, away from territory-cell boundaries. The touch helper reads current target geometry and hit-tests in one DOM evaluation, then uses locator-backed touch, tolerating same-label DOM reconciliation. The full 390×844 Worker → Extractor → Stonemason touch cycle passed, as did the 360×800 responsive smoke. These are Chromium-emulation results, not physical-device performance evidence.
- **Profession ability enforcement missing:** profession identity is not currently used by simulation job schedulers; catalog labels do not enforce the declared specialty jobs. This is a confirmed G7.2 gameplay gap, not a test-only failure. It remains FAIL pending implementation/product decision.
