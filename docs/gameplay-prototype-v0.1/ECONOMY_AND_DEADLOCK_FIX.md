# Экономика ×10 и восстановление логистики

Дата: 20 ноября 2026. Ветка: `feat/gameplay-prototype-v0.1`.
Экспериментальный локальный прототип; принятие владельцем после ручной игры ещё не заявлено.

## Воспроизведение и причина

До изменения симуляции точная последовательность «заполнить склад → грузчик становится строителем → дом → самостоятельные добытчики» прошла на новом поселении, включая девять задержек и восемь моментов reload. Поэтому утверждать, что именно она воспроизвела исходное сохранение владельца, нельзя.

Воспроизведено смежное полное зависание: у переназначенного жителя уже есть груз, все склады заполнены, затем он становится единственным строителем. Старая `updateResident()` возвращалась из проверки назначения груза до `planDelivery()`. Строитель не мог расходовать материалы склада, освобождающие место. Тест завершения дома на исходном коде падал.

Исправлено: полезный груз можно физически отвезти на нуждающуюся стройку; неподходящий груз единственного строителя при полной вместимости остаётся физическими партиями на земле. Это освобождает строителя для работы, сохраняя каждый материал. Новая добыча после последующего плейтеста вообще не забирает груз без доступного назначения.

Дополнительно исправлены собственный преждевременный резерв строителя, повторное резервирование уже поднятых материалов, зависшие неначатые заявки после смены профессии/режима, восстановление вместимости по одной единице вместо размера груза, потеря материалов при отмене стройки и при избыточной доставке. Заблокированная неполученная заявка больше не владеет фиктивным ресурсом или вместимостью.

## Баланс

| Параметр | Значение |
|---|---:|
| Начальный склад | 120 |
| Начальные дерево / камень | 30 / 20 |
| Дом | 60 / 50 |
| Дополнительный склад | 50 / 40 |
| Открытие клетки | 80 / 50 |
| Местная куча / переносимая партия | до 10 / до 10 |
| Домашний лес / камень | 320 / 300 |
| Восстановление единицы: лес / камень | 18 / 24 с |
| Новый лес: начальный запас / максимум / восстановление | 120 / 200 / 9 с |

Первоначальный вариант добывал до 10 за цикл и прошёл 98 unit-тестов и все 17 Chromium-сценариев (33,7 минуты). В живом сценарии до первого дома прошло 365,746 с. После нового ручного плейтеста эта механика заменена: **1 единица за 2,8 с**, сохранены цены ×10, груз до 10 и реальные маршруты. Строительная работа теперь 300 с на одного строителя, с ограничением обеспеченностью материалами и перекрытием доставки и строительства. Итоговая проверка и новые правила описаны в [OWNER_PLAYTEST_PRODUCTION_FIXES.md](OWNER_PLAYTEST_PRODUCTION_FIXES.md).

## Сохранения

Ключ `avanpost:gameplay-prototype:v01` сохранён. `economyVersion: 2` выполняет масштабирование ровно один раз. Запасы складов и источников, грузы, кучи и доставленные на стройки материалы масштабируются ×10. Старые грузы/кучи более 10 разделяются на физический груз до 10 и дополнительные наземные партии; ресурсы не обрезаются. В пути остаётся реальная партия, оставшаяся потребность снова попадает в очередь. Резервы и маршруты восстанавливаются по физическим количествам.

До миграции приложение сохраняет исходную строку в дополнительный ключ `:before-economy-v2` при наличии места. Основной ключ не меняется. Здания, заселённость, позиции зданий, профессии, прогресс строительства, сноса и расчистки сохраняются. Тесты проверяют точные количества до/после, повторную загрузку и отмену без дублирования. Сохранение владельца на публичном origin не сбрасывалось и не подменялось тестовым.

Актуальные окончательные результаты — в отчёте нового плейтеста. Отдельные регрессии находятся в `economy-deadlock.test.ts`: размеры грузов и резервов, повторные назначения и reload, отсутствие грузчика, диагностируемое ожидание, сохранность каждого ресурса на каждом шаге добычи/доставки/строительства с отдельным учётом природного восстановления.

Запуск: `npm run dev:gameplay-prototype`, адрес `http://127.0.0.1:7070/`. Production: `npm run build:gameplay-prototype`, затем `npm run preview -w @avanpost/gameplay-prototype -- --host 127.0.0.1 --port 7070 --strictPort`. Туннель владельца: https://tester.a.2na.am/. Изолированные тесты используют 4176.
