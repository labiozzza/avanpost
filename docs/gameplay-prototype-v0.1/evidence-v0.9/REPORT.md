## Что проверялось

Существующие сохранённые склады нормализуются в записи зданий, поэтому склад можно выбрать на карте и корректно привязать к земле. В карточке дома и склада добавлено безопасное действие **Снести здание**. Перед началом показываются возврат и ограничения; для работы нужен свободный строитель. После 15 секунд работы здание исчезает, его подготовленная площадка освобождается, а половина цены появляется рядом отдельными физическими кучами. Строитель без назначенного грузчика сам относит груз на склад. Остаток ресурсов считается в кучах, грузах жителей и складах, чтобы исключить потерю и повторный возврат после reload.

Снос запрещён для единственного склада, склада с запасами или активной перевозкой, а также дома, если после сноса вместимость жилья окажется ниже населения. Прогресс и назначенный строитель восстанавливаются после reload; действие можно отменить или продолжить. Повторное строительство на освобождённой площадке проходит обычную доставку и стройку.

## Браузерные проверки

Playwright использовал работающий локальный origin `http://127.0.0.1:4176`. Этот адрес уже обслуживался при запуске проверки; второй `vite preview` не запускался, потому что порт был занят. Отдельный запрос к `http://127.0.0.1:4175` вернул HTTP 200; повторный `npm run dev:gameplay-prototype` не стартовал из-за занятого порта. Останавливать существующие процессы не стал. Один layout-сценарий на 4175 прошёл.

Для чистой проверки запуска тот же workspace dev script был поднят на свободном порту командой `npm run dev -w @avanpost/gameplay-prototype -- --port 4177 --strictPort`. Vite сообщил `ready`, layout-сценарий прошёл, затем этот временный сервер был остановлен.

Первый полный запуск браузерного набора: **12/15 PASS, 3 FAIL**. Три сбоя были в тестовых ожиданиях: базовый склад теперь также представлен зданием; условие теста второго склада захватывало базовый склад; сценарий ожидал нетронутую кучу после того, как строитель уже начал её переносить. Ожидания исправлены. Все три упавших сценария затем прошли отдельными повторами (v0.9 — 2/2, миграция старого сохранения — 1/1, свежий длинный сценарий — 1/1). Полный набор не перезапускался одним проходом после правок, поэтому итог отмечен как **неполный общий повтор**, а не как PASS полного набора.
