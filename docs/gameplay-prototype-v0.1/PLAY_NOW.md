# AVANPOST Gameplay Prototype v0.1

Это экспериментальная Phaser-игра для локального плейтеста. Она не заменяет Peace V2, GDD или Peace Lite V1.

## Запуск на Windows

Откройте PowerShell в корне репозитория `E:\Avanpost-mvp-slice`. Если зависимости ещё не установлены:

```powershell
npm ci
```

Запустите игру в режиме разработки:

```powershell
npm run dev:gameplay-prototype
```

Откройте `http://127.0.0.1:7071/`. Для остановки нажмите `Ctrl+C` в окне сервера. Нужны Node.js 22+ и npm; PostgreSQL, V2 API и аккаунт не требуются.

## Запуск из WSL

Команды для репозитория на диске E::

```bash
cd /mnt/e/Avanpost-mvp-slice
npm ci
npm run dev:gameplay-prototype
```

Откройте `http://127.0.0.1:7071/` в Windows-браузере. WSL на этой машине не проверялся. Так как `node_modules` находится на общем диске E:, `npm ci` из WSL заменит установленный набор зависимостей; перед возвратом к Windows снова выполните `npm ci` в PowerShell.

## Production-сборка

Production проверяется отдельным статическим сервером, который обслуживает только опубликованный Vite build:

```powershell
npm run build:gameplay-prototype:production
$env:GAMEPLAY_PRODUCTION_PORT = '7073'
npm run serve:gameplay-prototype:production
```

Откройте `http://127.0.0.1:7073/`. У ответа есть заголовок `X-AVANPOST-Build`; `http://127.0.0.1:7073/_healthz` возвращает ID текущего релиза. Vite dev-сервер работает на `7071` и не является production.

## Первый игровой цикл

В действующей экономике только два ресурса:

- `wood` — **древесина**.
- `ore` — **порода** (общее название камня и металла).

Назначайте жителям лесозаготовку, добычу породы, перенос и строительство. Лесоруб рубит взрослые деревья партиями, каменщик добывает породу из начальной конечной залежи, грузчики физически переносят материалы. В старом интерфейсе может встретиться слово «каменщик» как название профессии; ресурс при этом называется «порода».

Цены текущего прототипа:

| Действие | Стоимость |
|---|---:|
| Первый дом | 60 древесины + 50 породы |
| Лесопилка на клетке взрослого дерева | 50 древесины + 40 породы |
| Первая шахта на залежи породы | 60 древесины |
| Улучшение дома до уровня 2 | 40 древесины + 30 породы |
| Посадка дерева | 10 древесины |

Первый дом добавляет место жителя. Шахта превращает конечную природную залежь в бесконечный источник породы. Лесопилка не производит доски: она увеличивает местную кучу древесины своего дерева с 10 до 50. Обычный склад вмещает 120 единиц каждого из двух ресурсов; шахта увеличивает местную кучу породы до 50. Вместимость кучи не меняет переносимую партию — до 10 единиц.

Чтобы посадить дерево, выберите свободную подготовленную поверхностную клетку и нажмите «Посадить дерево». Первый рост занимает около 120 секунд игрового времени; взросление продолжается в offline catch-up. После первой вырубки пень быстро восстанавливается, и лесоруб может повторять цикл без повторной посадки. Добыча не идёт без назначенного лесоруба.

Выберите дом через его карточку или список построек. Кнопка улучшения остаётся видимой при недостатке материалов и объясняет причину блокировки. Доставка ресурсов и работа строителя физические; смена профессии не стирает прогресс площадки.

## Короткий маршрут для плейтеста

1. Откройте «Жители» и назначьте Илью лесорубом, Марию каменщиком, Сашу грузчиком.
2. Дождитесь, пока на складе будет не менее 60 древесины и 50 породы. Запасы появляются после добычи и физической доставки.
3. В «Строить» выберите дом, нажмите на клетку № 3 и подтвердите размещение. Переназначьте Сашу строителем; стройка проходит три стадии и добавляет четвёртого жителя.
4. Назначьте нового жителя грузчиком. Соберите 50 древесины и 40 породы, постройте второй склад и дождитесь роста ёмкости до 240.
5. Соберите материалы для второго дома и продолжите развитие поселения. Перезагрузка должна восстановить людей, задания, запасы и постройки.

Реальный прогон первого дома на обычной скорости занял 7:28. Второй склад и второй дом проверены отдельным ускоренным Playwright-сценарием; его время не является оценкой обычного игрового темпа.

## Сохранения и миграция

Игра сохраняется в `localStorage` браузера под неизменным ключом `avanpost:gameplay-prototype:v01`. Не очищайте localStorage или Cache Storage для проверки обновления.

Старые сохранения мигрируют при загрузке без сброса: `stone` становится `ore`, каждая доска (`boards`) переводится в две единицы древесины, переполнение превращается в видимую локальную кучу, грузы и начатые работы сохраняются, лесопильщики переходят в лесорубы. Миграция идемпотентна; до неё сохраняется резервная копия старого JSON. Резервные копии можно скачать и импортировать из интерфейса.

Кнопка «Новая игра» требует подтверждения. Отмена сохраняет поселение. Прототип использует отдельный ключ и не читает сохранения Peace V2.

## Установка и запуск без сети

Для установки откройте production PWA по HTTPS и дождитесь сообщения **«Игра готова к запуску без интернета»**. Затем используйте команду «Установить» браузера; на iPhone/iPad — Safari → «Поделиться» → «На экран Домой».

После первой загрузки precache можно отключить сеть и выполнить холодный запуск приложения. Прогресс и кэш принадлежат конкретному браузерному origin. Проверка физического iPhone должна быть отдельно отмечена `NOT VERIFIED`, если устройство недоступно.
